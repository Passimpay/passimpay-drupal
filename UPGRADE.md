# PassimPay для Drupal Commerce — 1.0.1

1. Установите и настройте Drupal Commerce Payment. Перед обновлением сохраните файлы модуля и базу магазина.
2. Распакуйте каталог `passimpay/` из `passimpay_drupal.zip` в `modules/custom/passimpay/` либо замените файлы уже установленного модуля в его текущем расположении. Не создавайте вторую копию модуля и не удаляйте платёжный шлюз.
3. При первой установке включите модуль и создайте шлюз в `/admin/commerce/config/payment-gateways`. Машинное имя шлюза — `passimpay`. В Merchant ID укажите Platform ID, в IPN Secret — API Key проекта; Default currency — USD.
4. В проекте PassimPay задайте Notification URL: `https://shop.example/passimpay/ipn`, учитывая подкаталог магазина. Анонимной роли предоставьте разрешение `access commerce passimpay ipn`; подлинность уведомления проверяется подписью.
5. Выполните `drush cr` и контрольную оплату. Нужны PHP cURL, исходящий HTTPS к `https://api.passimpay.io` и действующее хранилище корневых сертификатов. API v2 используется автоматически.

Счета и платежи Commerce учитываются в USD. Для пересчёта позиций другой валюты нужен её курс в ответе PassimPay. Завершённая оплата записывается на сумму выставленного USD-счёта; криптосумма и хеш транзакции сохраняются в данных заказа.

После выставления счёта не меняйте сумму и валюту заказа: при расхождении автоматическое подтверждение блокируется. Для счёта, открытого до обновления и не содержащего сохранённой суммы, требуется ручная сверка с PassimPay. Такие счета разберите до обновления; ранее записанные платежи автоматически не пересчитываются.

Статус оплаты определяется серверной проверкой платежа. Адрес уведомлений должен принимать POST JSON и заголовок `x-signature` без перенаправлений и проверок браузера. Актуальные IP-адреса отправителей для настройки сервера получите у [поддержки PassimPay](https://passimpay.io/en/contacts); требования описаны в [документации уведомлений](https://passimpay.gitbook.io/passimpay-api/webhook).

Platform ID и API Key доступны в настройках проекта в [кабинете PassimPay](https://account.passimpay.io/).
